# ТехХаб - Маркетплейс научно-технических услуг

Платформа для студентов и преподавателей со всей России для поиска и выполнения научно-технических проектов.

## 🚀 Возможности

### Основной функционал
- **Регистрация и авторизация** - создание аккаунта с выбором роли (студент/преподаватель)
- **Личный кабинет** - профиль пользователя с рейтингом и отзывами
- **Доска заказов** - публикация и поиск проектов с фильтрацией по категориям
- **Система откликов** - исполнители могут предлагать свои услуги с указанием цены
- **Чат** - встроенная система сообщений между заказчиком и исполнителем
- **Внутренний кошелёк** - пополнение баланса и вывод средств
- **Система рейтингов** - оценки и отзывы после завершения работ
- **Настройка профиля** - резюме с навыками, биографией и контактами

### Категории услуг
- Разработка
- Дизайн
- Инженерия
- Научные исследования
- Анализ данных
- Другое

## 🛠 Технологии

- **Backend**: Python 3.12, Flask 3.0
- **База данных**: SQLite (Flask-SQLAlchemy)
- **Аутентификация**: Flask-Login
- **Формы**: Flask-WTF
- **Frontend**: HTML5, CSS3, Bootstrap 5.3
- **JavaScript**: ванильный JS

## 🚀 Запуск приложения

### Установка зависимостей
```bash
cd techhub
pip install -r requirements.txt
```

### Запуск сервера
```bash
python app.py
```

Приложение будет доступно по адресу: http://localhost:5000

## 📝 Использование

### Для заказчиков (преподавателей)
1. Зарегистрируйтесь и войдите в систему
2. Создайте новый заказ с описанием задачи и бюджетом
3. Просматривайте отклики исполнителей
4. Выберите подходящего исполнителя и примите его отклик
5. Общайтесь в чате и контролируйте выполнение
6. После завершения оставьте отзыв

### Для исполнителей (студентов)
1. Зарегистрируйтесь и заполните профиль (навыки, биография)
2. Просматривайте доступные заказы с фильтрацией
3. Откликайтесь на интересные проекты
4. Общайтесь с заказчиками в чате
5. Выполняйте работу и получайте оплату
6. Получайте отзывы и повышайте рейтинг

## 💰 Платёжная система

- **Пополнение**: мгновенное зачисление средств на внутренний счёт
- **Вывод**: на банковскую карту, через СБП или ЮMoney (1-3 дня)
- **Комиссия**: 10% от суммы сделки
- **Гарантии**: безопасная сделка через резервирование средств

## 🔐 Безопасность

- Хэширование паролей (Werkzeug)
- Защита от CSRF-атак (Flask-WTF)
- Сессионная аутентификация
- Валидация пользовательских данных

## 📊 Модели данных

- **User** - пользователи (студенты и преподаватели)
- **Order** - заказы/проекты
- **Bid** - отклики на заказы
- **Message** - сообщения в чате
- **Review** - отзывы и оценки
